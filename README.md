# App Ratings Analysis
This repository contains a data analysis project comparing app ratings across different platforms (Google Play and Apple App Store). The analysis employs statistical methods, including permutation testing, to determine whether platform influences app ratings.

## Project Overview
This project follows a structured approach to testing the null hypothesis that platform does not impact app ratings. The key steps include:

 - Exploratory Data Analysis (EDA): Visualizing rating distributions using boxplots and histograms.
 - Permutation Testing: Simulating 10,000 shuffled distributions of ratings to create a null distribution.
 - Hypothesis Testing: Calculating a p-value to determine statistical significance.
## Key Findings
 - The observed difference in mean ratings between platforms was 0.14206.
 - A permutation test with 10,000 simulations was conducted to assess significance.
 - The resulting p-value indicated whether the difference was statistically significant.
